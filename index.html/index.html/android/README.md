# Android (Capacitor)

Package: `app.mechanicshelper` · `versionCode 2` / `versionName 1.0.1`. This module is generated by Capacitor on the production app root (`index.html/index.html`, the Railway `rootDirectory`).

Full Play Console / signing / AAB steps: **[docs/PLAY_STORE.md](../../../docs/PLAY_STORE.md)** at the git root.

```bash
cd index.html/index.html
npm run cap:sync
npm run android:assemble   # debug APK
npm run android:bundle     # release AAB — unsigned unless android/keystore.properties exists
```

Leon signs on his machine: add `android/keystore.properties` + `android/release.keystore`, then `npm run android:bundle`. Never commit those files.
