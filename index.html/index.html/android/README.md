# Android (Capacitor)

Package: `app.mechanicshelper`. This module is generated by Capacitor on the production app root (`index.html/index.html`, the Railway `rootDirectory`).

Full Play Console / signing / AAB steps: **[docs/PLAY_STORE.md](../../../docs/PLAY_STORE.md)** at the git root.

```bash
cd index.html/index.html
npm run cap:sync
npm run android:assemble   # debug APK
npm run android:bundle     # release AAB (needs android/keystore.properties)
```
