# Generic vehicle stills

These `/img/car-*.jpg` files are **original project-owned art** created for Mechanics Helper.

- Source: generated for this repository (not scraped from OEM, dealer, or brand stock sites).
- Purpose: anonymous body-type fallbacks — sedan, hatchback, coupe, crossover/SUV, truck, van/minivan, sports.
- Constraints: no manufacturer badges, logos, license plates, or model-specific twins (no Mustang / Wrangler / BMW-kidney / Civic clones).
- Paint: light pearl-silver so an optional color overlay can tint the same base art.
- Customer or ticket photos always win when present; these files are fallback only.
